## 🚀 Instalace a spuštění

### Požadavky
- Webový prohlížeč (Chrome, Firefox, Safari, Edge)
- Webový server (volitelné pro lokální vývoj)

### Rychlé spuštění

1. **Klonování repozitáře**
   ```bash
   git clone https://github.com/MIRIS888/Prometica_web.git
   cd Prometica_web
   ```

2. **Spuštění lokálně**
   
   **Možnost A: Přímo v prohlížeči**
   - Otevřete soubor `index.html` v prohlížeči
   
   **Možnost B: Lokální server (doporučeno)**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (pokud máte nainstalováno)
   npx serve .
   
   # PHP
   php -S localhost:8000
   ```

3. **Otevření v prohlížeči**
   - Přejděte na `http://localhost:8000` (pokud používáte server)
   - Nebo přímo otevřete `index.html`

## 🎨 Customizace

### Změna barev
Hlavní barvy jsou definovány v `:root` v `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #06b6d4;
    /* ... další barvy */
}
```

### Přidání nové sekce
1. Přidejte HTML strukturu do `index.html`
2. Přidejte styly do `styles.css`
3. Případně přidejte interaktivitu do `script.js`

## 🌐 Deployment

### GitHub Pages
1. Pushněte kód na GitHub
2. Jděte do nastavení repozitáře
3. Zapněte GitHub Pages v sekcích Pages
4. Vyberte hlavní branch jako zdroj

### Netlify
1. Připojte GitHub repozitář
2. Netlify automaticky detekuje statický web
3. Deploy proběhne automaticky

### Vercel
1. Importujte projekt z GitHubu
2. Vercel automaticky nasadí statický web
